# VisitIndonesia.co.id — Vercel-ready Stitch build

## Pages
- `/` — Home
- `/experiences` — Explore Experiences
- `/jakarta-heritage` — Jakarta Heritage Experience
- `/fmcg-market` — FMCG & Retail Business Experience
- `/business` — Enter Indonesia Advisory

## Deploy
Upload the contents of this folder to a GitHub repository and import that repository into Vercel.
No build command is required. Vercel serves the static HTML files and `vercel.json` maps the clean URLs.

The design remains based on the original Stitch output. Images/fonts remain externally hosted exactly as supplied by the prototype.
